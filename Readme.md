# Information Security Repository

This repository contains Java implementations of various information security concepts and algorithms. The focus is on classical ciphers, modern encryption techniques, cryptographic algorithms, authentication systems, and access control mechanisms.

## Prerequisites
- Java Development Kit (JDK) 8 or later
- Recommended IDE: IntelliJ IDEA

### Classical Ciphers
This section includes implementations of classical encryption methods:
- **Caesar Cipher**: A substitution cipher that shifts characters by a fixed number.
- **Playfair Cipher**: A digraph substitution cipher.
- **Rail Fence Cipher**: A transposition cipher that writes messages in a zigzag pattern.

### Modern Encryption Algorithms
This section covers modern symmetric encryption techniques:
- **DES (Data Encryption Standard)**: A symmetric-key block cipher.
- **AES (Advanced Encryption Standard)**: A symmetric encryption standard widely used today.

### Cryptographic Techniques
Explore fundamental cryptographic algorithms:
- **Primality Testing**: Algorithms to determine if a number is prime.
- **Euclidean Algorithm**: A method for computing the greatest common divisor (GCD).
- **RSA (Rivest-Shamir-Adleman)**: A public-key encryption algorithm widely used for secure data transmission.

### Hashing Algorithms
Implementations of popular hashing algorithms:
- **MD5**: A widely used cryptographic hash function that produces a 128-bit hash value.
- **SHA (Secure Hash Algorithm)**: A family of cryptographic hash functions, including SHA-1, SHA-256, etc.

### Authentication Systems
This section includes code for various authentication mechanisms:
- **Password-Based Authentication**: Simple user authentication using passwords.
- **Captcha**: Implementation of a CAPTCHA to differentiate between humans and bots.
- **Two-Factor Authentication (2FA)**: An extra layer of security using two different forms of identification.

### Access Control
- **Role-Based Access Control (RBAC)**: A method for regulating access to resources based on the roles of individual users within an organization.
